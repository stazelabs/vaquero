## Shortcuts

| Key | What it does |
|---|---|
| `c` | New ticket, in the project you are looking at |
| `/` | Search |
| `g b` | Board |
| `g l` | List |
| `j / k` | Next or previous card on the board |
| `enter` | Open the card |
| `?` | Show these shortcuts |
| `esc` | Close the shortcuts, or leave the search box |

## When they work

Shortcuts are ignored while you type in a field, so typing a `c` in a comment never opens a new ticket. `g b` and `g l` work on any page of a project. Enter on a focused link or button does what that link or button does.
