## Shortcuts

| Key | What it does |
|---|---|
| `c` | New ticket in the project you are looking at; elsewhere, new project |
| `/` | Search |
| `g b` | Board |
| `g l` | List |
| `j / k` | Focus the next or previous card on the board or list |
| `enter` | Open the focused card |
| `?` | Show these shortcuts |
| `esc` | Close a dialog; on a narrow screen, close an open rail |

## When they work

Shortcuts are ignored while you type in a field, so typing a `c` in a comment never opens a new ticket. `g b` and `g l` go to the board and list of the project you are looking at (from its board, list or a ticket); elsewhere they go to the projects list. Enter on a focused link or button does what that link or button does. `j` and `k` move the keyboard focus itself, so Tab carries on from the card they reached, and they start from whichever card has focus.
