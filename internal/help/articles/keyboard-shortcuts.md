## Shortcuts

| Key | What it does |
|---|---|
| `c` | New ticket in the project you are looking at; elsewhere, new project |
| `/` | Search |
| `g b` | Board |
| `g l` | List |
| `j / k` | Next or previous card on the board |
| `enter` | Open the card |
| `?` | Show these shortcuts |
| `esc` | Close the shortcuts |

## When they work

Shortcuts are ignored while you type in a field, so typing a `c` in a comment never opens a new ticket. `g b` and `g l` go to the board and list of the project you are looking at (from its board, list or a ticket); elsewhere they go to the projects list. Enter on a focused link or button does what that link or button does.
