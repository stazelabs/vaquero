# The editor Implementation Plan (VAQ-6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every body box becomes a Markdown editor where a pasted image shows in place (new ticket included), typing a ticket key suggests tickets, rendered Markdown links ticket keys, and the title, description and one's own comments are edited by clicking them on the ticket page, with the stored text exactly the Markdown typed.

**Architecture:** A vendored CodeMirror 6 bundle mounts over today's `<textarea>` (which stays the form value and the no-JavaScript editor). New-ticket pastes go to core's `pending_attachments`, claimed by the ticket's creation. Click to edit swaps rendered sections for the editor through htmx and saves through two field-only routes.

**Tech Stack:** Go 1.27, templ, htmx, CodeMirror 6 (vendored), npm (already used for Tailwind and Lucide, at build time only), SQLite.

**Spec:** `docs/superpowers/specs/2026-11-26-editor-design.md`.

## Global Constraints

- Gate before every commit touching Go, SQL, templ, CSS or JS: `make gen && make fmt && make vet && make lint && make test`, plus `make e2e` for every task here from Task 2 on (each changes pages or app.js).
- Commit messages `{Area}: {summary} (VAQ-6)`, ending with the `Co-Authored-By` line.
- CSP after Task 1: `style-src 'self' 'nonce-{nonce}'`; `style=` attributes and un-nonced style elements stay refused; no inline script; no `<svg>` in templates; theme tokens only.
- The saved body equals what was typed, byte for byte: the editor never normalises text (no trailing-space trimming, no list renumbering, no line-ending change beyond the browser's `\r\n` → `\n` the textarea already does).
- Without JavaScript every box is today's textarea and every save works.
- `pending_attachments` is written only by core, with no event (owner); CLAUDE.md records it beside heartbeats.
- Image previews in the editor: only `/attachments/{id}/…` destinations, at most the box's width and 480 px tall.
- Copy (exact): "Uploading {name}…", "Add a description", "This ticket changed since you opened it.", Edit control label "Edit".

## Review Focus

1. **Pasting a 12 MB image, or a file while offline:** the size check refuses before upload with the existing toast; an upload that fails removes its placeholder and keeps every other character. Test in Task 2.
2. **Typing in the description while an agent comments on the ticket:** the live refresh waits; on save the comment appears and the typed text is saved. Test in Task 5.
3. **A ticket key inside inline code, a link, a URL or a heading anchor** (`` `VAQ-1` ``, `[x](/t/VAQ-1)`, `https://x/VAQ-1`): not linked again, not broken. Test in Task 3.
4. **Two new-ticket tabs open at once, each pasting files:** each ticket gets only its own draft's files. Test in Task 4.
5. **Clicking a link, image or ticket key inside the description:** follows it, never opens the editor. Test in Task 5.
